현재 국내 채용 시장에서 찬민 님의 이력은 다음 3개 영역의 **완벽한 교집합**에 위치합니다:

```
    [1. 글로벌/영어 소통]
    (원어민급 영어, 해외 개발팀 리딩)
              ∩
    [2. 테크니컬 백엔드/AI 이해도]
    (API, DB 프로시저, AWS FinOps, AI 모델)
              ∩
    [3. B2B 엔터프라이즈 운영/기획]
    (조선호텔, 코람코, 골드앤에스 유저플로우)
              ↓
  ★ High-Impact Global Technical PM / PO ★
```

## 2. 가장 높은 가치로 인정받을 수 있는 타깃 기업군 3선

### 🏢 1순위: 글로벌 비즈니스를 영위하는 AI / B2B SaaS 유니콘 & 스케일업
- **추천 기업군**: 센드버드(Sendbird), 채널톡(Channel Corp), 몰로코(Moloco), 업스테이지(Upstage), 뤼튼(WRTN), 마크비전(MarqVision), 스푼라디오 등.
- **매칭 강점**:
  - 해외 개발자/현지 오피스와 영어로 일하는 문화가 이미 기본 장착된 곳.
  - 찬민 님의 **"인도 엔지니어링 파트너사 테크 스크럼 리딩 + AI 웹 개발 최우수상"** 이력이 가장 강력한 서류 프리패스 요인으로 작용.

### 🏢 2순위: 스마트빌딩 / 프롭테크 / 공간·모빌리티 플랫폼
- **추천 기업군**: 직방, 스파크플러스, 패스트파이브, 쏘카(SOCAR), 카카오모빌리티, 알스퀘어 등.
- **매칭 강점**:
  - 찬민 님이 이미 현업에서 담당하신 **조선호텔앤리조트(센터필드), 코람코(그랑서울)의 스마트 오피스 QR 출입·예약·주차 라이브 시스템 운영 경험**과 직결.
  - B2B 빌딩 솔루션의 고충과 하드웨어-소프트웨어 연동 이슈를 이미 겪어본 희소한 PM 인재로 즉각 투입 가능.

### 🏢 3순위: 글로벌 진출을 추진 중인 차세대 에듀테크 플랫폼
- **추천 기업군**: 뤼이드(Riiid), 매스프레소(콴다), 데이원컴퍼니(패스트캠퍼스), 팀스파르타, 퀄슨 등.
- **매칭 강점**:
  - **골드앤에스 토킹클럽 119개 어드민/33개 앱 화면 런칭 총괄, Bookr Class SSO, 학부모/학생/강사 권한 체계 설계 경험**이 100% 재현 가능한 도메인 전문성으로 인정받음.
