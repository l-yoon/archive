> [!NOTE] 핵심 요약
> **Aside**([aside.com](https://aside.com) / [meetaside.com](https://meetaside.com))는 Y Combinator 출신의 차세대 AI 에이전트 플랫폼으로 크게 두 가지 축으로 구성됩니다:
> 1. **Aside AI Browser**: 복잡한 다단계 웹 워크플로우를 인간처럼 수행하는 에이전틱 Chromium 브라우저 (BYO 구독, 시큐어 패스워드 매니저, CLI/MCP 지원).
> 2. **Aside Meeting Copilot**: 화상 미팅 및 인터뷰 중 실시간 질문을 감지해 적시 답변과 맥락 큐카드를 즉시 띄워주는 프라이버시 중심 실시간 코파일럿.

---

## 1. 개요 및 등장 배경

기존의 AI 어시스턴트(웹 챗봇, IDE 확장 프로그램)는 브라우저 내부의 실제 업무 환경과 단절되어 있었습니다. 회사의 어드민 대시보드, 스프레드시트, 사내 인트라넷, 이메일 등 실제 업무가 일어나는 웹 세션에 AI가 직접 접근하기 어려웠기 때문에 사용자가 일일이 화면을 캡처하거나 텍스트를 복사-붙여넣기해야 했습니다.

또한 회의나 고객 인터뷰 중 돌발 질문이나 기술 사양 질문이 들어왔을 때 실시간으로 필요한 자료를 검색하고 답변을 구성하는 데 한계가 있었습니다.

**Aside**는 이 두 가지 병목을 해결하기 위해 **직접 웹 세션을 조작하는 'AI 브라우저'**와 **실시간 대화를 보조하는 '미팅 코파일럿'**을 제공합니다.

---

## 2. Aside AI Browser: 다단계 웹 에이전트 워크스페이스

Aside AI Browser는 웹 브라우징과 에이전트 자동화가 하나로 결합된 전용 브라우저입니다.

### 1) 실로그인 세션 기반의 직접 인터랙션
- API가 제공되지 않는 복잡한 웹 서비스(ERP, 사내 관리자 콘솔, 결제 대시보드 등)에서도 사용자가 로그인해 둔 브라우저 세션을 그대로 활용하여 작업합니다.
- 클릭, 입력, 탭 전환, 엑셀/CSV 데이터 다운로드 및 가공 등 브라우저 내 일련의 업무를 자율적으로 수행합니다.

### 2) BYO Subscription (구독 연동 및 BYOK)
- 고가의 전용 크레딧을 별도로 구매할 필요 없이, 사용자가 기존에 보유하고 있는 **Claude Pro/Team, ChatGPT Plus/Pro 계정 또는 개인 API 키**를 그대로 연결(BYO Subscription)할 수 있습니다.
- 사용자에게 가장 익숙하고 최신 추론 능력을 가진 모델을 브라우저 에이전트의 두뇌로 지정할 수 있습니다.

### 3) 시큐어 패스워드 매니저 & 권한 가드레일
- 보안상 가장 중요한 비밀번호나 인증 토큰을 원시 텍스트(Raw Text) 형태로 LLM 모델에 노출하지 않습니다.
- 내장된 보안 키체인 매니저가 안전하게 로그인을 중개하며, 결제나 데이터 삭제 같은 민감한 작업은 사용자 승인을 거치도록 설계된 Guardrail 정책을 적용합니다.

### 4) CLI 및 MCP(Model Context Protocol) 지원
- 개발자 도구 및 터미널 환경과의 연동을 기본 지원합니다.
- **Claude Code**나 **Cursor** 같은 코딩 에이전트가 Aside의 브라우저 인스턴스를 MCP 도구로 호출하여, "로컬에서 실행 중인 웹 서버에 접속해서 회원가입 플로우 UI 버그를 재현하고 콘솔 로그를 가져와"와 같은 복합 작업을 브라우저 단에서 직접 수행할 수 있습니다.

## 3. Aside Meeting Copilot: 실시간 대화 지원

[meetaside.com](https://meetaside.com)에서 제공하는 데스크톱 전용 실시간 코파일럿 앱은 온라인 회의 및 면접의 생산성을 극대화합니다.

### 1) 실시간 질문 감지 및 즉각적인 큐카드 ("Right when they ask")
- 상대방이 질문을 던지는 순간 로컬 오디오 스트림을 실시간 감지하여, 답변에 필요한 핵심 수치, 제품 사양, 사전 메모된 컨텍스트를 화면 한구석에 은밀하게 띄워줍니다.
- 복잡한 제품 기능 설명이나 기술 면접, 고객사 세일즈 콜에서 머뭇거림 없이 정확한 사실을 전달할 수 있습니다.

### 2) 로컬 우선(Privacy-First) 처리
- 회의 전체 내용을 무차별하게 외부 클라우드로 전송하지 않고, 키워드와 컨텍스트 탐색을 사용자 컴퓨터에서 우선 처리합니다.
- 하드웨어 가속(GPU/NPU)을 지원하여 지연 시간(Latency)을 최소화했습니다.

## 4. 기능 및 아키텍처 비교

| 비교 항목 | 전통적 웹 브라우저 + 확장도구 | 클라우드 AI 에이전트 (API 기반) | **Aside (AI Browser & Copilot)** |
| :--- | :--- | :--- | :--- |
| **웹 직접 조작** | 단순 스크래핑/요약 수준 | API가 열린 서비스만 가능 | **인간처럼 로그인 세션 내 완벽 조작** |
| **비용 모델** | 개별 확장프로그램 구독 | 토큰당 종량제 과금 | **BYO Subscription (기존 Claude/GPT 연동)** |
| **보안 체계** | 브라우저 쿠키 탈취 위험 | 토큰 전송 보안 문제 | **시큐어 패스워드 매니저 + 모델 비노출** |
| **에이전트 연동** | 불가 | 커스텀 API 빌드 필요 | **CLI & MCP 공식 지원 (Claude Code 등)** |
| **회의 실시간 보조** | 미지원 (별도 봇 필요) | 사후 요약 위주 | **실시간 로컬 큐카드 & 지연 없는 답변 보조** |

## 5. 실무 활용 시나리오

1. **사내 내부 툴 리포트 자동 취합**:
   - Aside 브라우저에 "월요일 오전 9시마다 내부 어드민 대시보드 3곳에 접속해서 지난주 가입자 지표를 추출한 뒤 구글 스프레드시트에 기입해줘" 지시.
2. **기술 영업 및 파트너십 미팅**:
   - MeetAside를 켜둔 상태에서 클라이언트가 "귀사 인프라의 가용성 SLA와 SOC2 인증 현황이 어떻게 되나요?"라고 물으면, 사내 보안 규정 문서를 바탕으로 즉시 수치와 레퍼런스를 화면에 요약 제시.
3. **Claude Code 연동 E2E 테스트**:
   - 로컬 개발 환경에서 작성된 웹 앱을 Aside 브라우저를 통해 Claude Code가 직접 조작하면서 회원가입 플로우와 엣지 케이스를 테스트하고 결과 리포트 수신.
