[OpenBot](https://openbot.run/)은 내 컴퓨터 백그라운드에 띄워두고 일 시키는 오픈소스 멀티 에이전트 플랫폼이다.

---

### 웹 챗봇과 뭐가 다른가?
브라우저 탭 닫으면 기억을 잃는 웹 챗봇과 달리, **로컬 워크스페이스에서 지속적으로 살아 움직인다**:
- **진짜 컴퓨터 조작 권한**: 파일 입출력, 터미널 쉘 실행, 브라우저 자동화를 백그라운드에서 자율적으로 수행한다.
- **내 구독 그대로 사용 (BYO)**: 별도 중간 마진 없이 기존 Claude Pro, ChatGPT Plus 계정이나 개인 API 키를 연결한다.
- **역할별 에이전트 분리**: 리팩토링 전담봇, QA 테스트 전담봇, 아침 뉴스 리서치 전담봇을 각각 독립된 디렉토리 권한으로 굴린다.
- **모바일 앱 지원**: 컴퓨터에서 작업 돌려두고 외출해도 iOS/Android 모바일 앱으로 진행 상황 확인과 승인이 가능하다.

---

### 결론
CLI 코딩 에이전트(Claude Code 등)가 개발자 혼자 터미널에서 치는 도구라면, OpenBot은 여러 에이전트를 백그라운드에 상주시키고 팀처럼 굴리고 싶을 때 쓰는 GUI 허브다.
