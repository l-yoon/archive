---

## 1. UI/UX & 디자인 엔지니어링

* **[shadcn/ui](https://ui.shadcn.com/)**: Radix UI + Tailwind CSS 기반의 복사-붙여넣기형 컴포넌트 라이브러리. 의존성 없이 코드를 직접 소유할 수 있어 커스텀에 최적.
* **[Lucide Icons](https://lucide.dev/)**: Feather Icons의 포크로 유지보수가 가장 활발하며 일관된 24x24 그리드 제공.
* **[Mobbin](https://mobbin.com/)**: 글로벌 모바일 및 웹앱의 실시간 스크린샷과 유저 플로우 아카이브.
* **[Pageflow](https://pageflows.com/)**: 온보딩, 결제, 탈퇴 등 핵심 사용자 여정(User Flow) 비디오 레퍼런스.

---

## 2. AI & LLM 개발 생태계

* **[Anthropic MCP Documentation](https://modelcontextprotocol.io/)**: MCP 공식 프로토콜 명세서 및 TypeScript/Python SDK.
* **[LangSmith / LangFuse](https://langfuse.com/)**: 오픈소스 LLM 트레이싱, 모니터링, 프롬프트 버전 관리 도구.
* **[OpenRouter](https://openrouter.ai/)**: 단일 API 키로 모든 주요 LLM(Claude, GPT, Llama, Gemini) 라우팅 및 폴백 지원.

---

## 3. 인프라 & 데이터베이스

* **[Cloudflare Pages / Workers](https://pages.cloudflare.com/)**: 글로벌 엣지 배포 및 초경량 서버리스 함수. 본 Quartz 블로그의 최적 호스팅 환경.
* **[Supabase](https://supabase.com/)**: 오픈소스 Firebase 대안 (PostgreSQL, Row Level Security, 실시간 구독).
* **[Neon](https://neon.tech/)**: 서버리스 Postgres (Branching 지원, 로컬 개발/스테이징 분리에 탁월).
